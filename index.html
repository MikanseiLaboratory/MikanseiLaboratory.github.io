About

未完成成果物研究所について

完成品を売る会社ではない。配信用のツールとハードウェアを、収録の合間に直して、翌日の卓に戻す。名前の「未完成」は、その途中経過を出す、という意味でもある。

2026年時点で、メンバーは放送・配信・ITの仕事が本業だ。研究所の作業は空き時間で回している。

Our approach

考え方

机上の理想だけだと、収録の当日に使えない。今のやり方に合わせるだけでも、手数は減らない。荒くても、明日の番組でボタンを減らせるものを出す。

What we do

やっていること

vMix や ATEM の周辺ソフト、専用パネル、Stream Deck と Companion のプラグイン。NDI・OMT・SRT の実装も書く。ゲームの API をテロップや HUD に載せる仕事も受ける。

Projects

プロダクトとプロジェクト

製品、公開ソフト、ライブラリと試作に分けた。並びは active、development、experimental、research の順。

製品

手元で切るためのパネル

  • Iryx

    development

    vMix 専用のコントロールパネル。トランジション用とリプレイ用を、いま並行して作っている。

    vMix Hardware

  • ATEM Micro

    development

    Blackmagic Design ATEM 向けの小型コントロールパネル。開発中。

    ATEM Hardware

OSSソフトウェア

現場の卓で使う公開ソフト

  • OMT Tools

    active

    Open Media Transport 向けの無料ツール。Studio Monitor と Test Patterns。LAN 上の映像確認用。

    OMT Windows macOS

  • vmix-utility

    active

    vMix の接続と操作をまとめるデスクトップアプリ。Shortcut、Blank、Input、List。

    vMix Tauri

  • bi-kanpe

    active

    双方向のカンペ。オフライン前提。iOS / Android と Stream Deck から送れる。

    Prompt Stream Deck

  • ProductionDeck

    active

    オープンソースの Stream Deck 互換ファームウェア。Raspberry Pi Pico（RP2040）向け。

    RP2040 Firmware

  • obs-sync

    development

    複数の OBS を同じ進行に揃える。投影用と配信用を分けたいとき、予備系を置きたいときに使う。

    OBS Sync

  • ATEM-UI

    development

    ATEM Software Control のオープンソース代替。Linux を含む、複数 OS から ATEM を操作する。

    ATEM Rust

  • stream-monitor

    experimental

    Twitch の同時接続数とチャット密度を見る実験。配信の山場を後から拾うためのもの。

    Twitch Analytics

  • rust-ndi-viewer

    research

    Rust だけで NDI を受信して表示する。CPU と WGPU のフィルタもサンプルとして置いてある。

    Rust NDI WGPU

ライブラリや試作品

プロトコル実装、クレート、プラグイン、試作

  • vmix-rs

    active

    vMix の TCP / HTTP API を叩く Rust ライブラリ。crates.io に出している。

    Rust vMix

  • openmediatransport-rs

    active

    OMT の Pure Rust 実装。TCP 伝送と DNS-SD 発見。Sender と Receiver がある。

    OMT Rust

  • vmx-rs

    active

    VMX1 コーデックの Pure Rust 実装。AVX2 / SSE / NEON / scalar の SIMD 経路がある。

    VMX SIMD

  • streamdeck-atem-rs

    development

    Blackmagic Design ATEM 向けのクロスプラットフォーム Stream Deck プラグイン（Rust）。

    ATEM Stream Deck

  • momaku（網膜）

    experimental

    Web ページを NDI で送出するデスクトップアプリ。Vingester にインスパイアされている。

    NDI Tauri

  • necromancer

    research

    Blackmagic ATEM 制御プロトコルの Pure Rust 再実装。まだ製品としては出していない。

    ATEM Protocol
