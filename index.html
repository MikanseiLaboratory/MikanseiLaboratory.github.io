About

未完成成果物研究所について

未完成成果物研究所は、配信プロダクション向けツールおよびハードウェア機材の研究開発を行う技術者コミュニティです。

「完成」の一歩手前にある、荒削りながらも本質的な課題解決を目的としています。2026年現在、全メンバーが放送・配信・IT業界の第一線で活動するプロフェッショナルであり、本業の傍ら、技術的探求と現場の最適化を目的として参画しています。

What we do

やっていること

vMixやTriCaster、ATEMの周辺ソフトや専用パネル、StreamDeckプラグイン、NDI・OMT・SRT関連のソフトウェアを開発しています。ゲームのAPIと連動したグラフィックシステムやテロップシステムの開発も行っています。

OSSソフトウェア

プロダクション現場や配信スタジオ、中継車などで利用するソフトウェア群です。

  • OMT Tools

    active

    Open Media Transport(OMT)向けの無料ツール群。NDI Toolsにインスパイアされたソフトウェア群です。

    OMT Windows macOS

  • vmix-utility

    active

    vMixへの接続と操作を包括的に支援するデスクトップアプリ。多くのイベントで採用実績あり。

    vMix Tauri

  • bi-kanpe

    active

    オフライン環境でも使える双方向カンペ。iOS / Android および StreamDeck から送信できます。

    Prompt StreamDeck

  • ProductionDeck

    active

    オープンソースのStreamDeck互換ファームウェア。Raspberry Pi Pico(RP2040)、STM32H7シリーズ向け。ハードウェアも近日公開予定。

    RP2040 Firmware

  • obs-sync

    development

    LAN内の複数のOBS-Studioを同じ状態に揃える支援ソフトウェア。投影用と配信用を分けたいときや、予備系を置きたいときに使う。

    OBS Sync

  • ATEM-UI

    development

    ATEM Software Controlのオープンソース代替。Linuxを含む複数OSからATEMの制御・操作が可能

    ATEM Rust

  • stream-monitor

    experimental

    Twitchの同時接続数とチャット密度を見る実験的BIデスクトップアプリ。

    Twitch Analytics

  • rust-ndi-viewer

    research

    RustだけでNDIを受信して表示するPoCデスクトップアプリ。CPUとWGPUのフィルターサンプルコードも配置。

    Rust NDI WGPU
