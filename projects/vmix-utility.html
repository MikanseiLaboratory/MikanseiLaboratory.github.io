vmix-utility

vMixの管理とオペレーションを支援する

vMixを支援する配信・収録向けのデスクトップアプリ。複数台のvMixの管理、Shortcut URLの組み立て、Blank入力の一括作成、InputとListの確認などが可能です。

ダウンロード（最新） GitHub 機能を見る
  • Windows（.msi）
  • macOS（.dmg / Intel · Apple Silicon）

Stack

構成

Tauri

Rust/Reactで開発しています。ビルド成果物を Windows / macOS / Linux 向けに出しています。

vMix API

HTTP / TCP経由で接続し、vMixの状態をリアルタイムに監視・更新します。

現場前提

シーン切替のスピード感が速いesportsイベントや、スライド素材の枚数が多いイベントでの運用を想定しています。

Features

含まれる機能

利用できる機能群です。接続先vMixを登録したうえで、必要な作業画面へ切り替えます。

  • Connections

    vMixホストを追加・管理します。複数台・予備系を切り替えて使う現場向けです。

  • Shortcut Generator

    Shortcut FunctionのURLを組み立てます。StreamDeckやブラウザ経由でのvMix操作が可能になります。

  • Blank Generator

    Blank / Colours 入力を一括生成します。合成シーンを大量に作成する際に仕様します。

  • Input Manager

    Inputを閲覧・管理します。vMix本体の入力監視や、名前の変更を一括で行ったり別PCから実現が可能になります

  • List Manager

    Input Listを閲覧・管理します。素材数や差し替えが多い番組での確認用です。

  • Settings / About

    設定に加え、リポジトリ・ライセンス・Discord・支援案内をまとめた画面があります。

Use cases

主な用途・利用例

  • シーン数が多くスイッチングが多い番組で、ショートカット整理の負荷を下げる
  • 社内・学校などで繰り返し使うフォーマット配信に、テンプレート化しやすい運用を載せる
  • Blank入力やListの準備を、本番前のセットアップ時間にまとめて片付ける
