vmix-utility

vMix 接続とオペレーションを最適化する

vMix を中核にした配信・収録向けのデスクトップアプリ。接続の管理、Shortcut URL の組み立て、Blank 入力の一括作成、Input と List の確認。卓の定型作業の手数を減らすために書いている。

ダウンロード（最新） GitHub リポジトリ 機能を見る
  • Windows（.msi）
  • macOS（.dmg / Intel · Apple Silicon）
  • Linux（.AppImage）

Stack

構成

Tauri

Rust バックエンドと React フロントエンド。ネイティブ配布物を Windows / macOS / Linux 向けに出しています。

vMix API

HTTP / TCP 経由で接続し、Shortcut や Input 状態を扱います。下回りには vmix-rs も公開しています。

現場前提

進行ディレクターとオペレーターが分かれる番組、シーン切替の多い esports、繰り返しフォーマットの配信を想定しています。

Features

含まれる機能

README に公開しているモジュールです。接続先を登録したうえで、必要な作業画面へ切り替えます。

  • Connections

    vMix ホストを追加・管理します。複数台・予備系を切り替えて使う現場向けです。

  • Shortcut Generator

    Shortcut Function の URL を組み立てます。Stream Deck やブラウザ起点の操作に渡せます。

  • Blank Generator

    Blank / Colours 入力を一括生成します。セットアップ時のプレースホルダ作りを短縮します。

  • Input Manager

    Input を閲覧・管理します。本線の入力一覧を、vMix 本体の画面以外からも確認できます。

  • List Manager

    Input List を閲覧・管理します。クリップ順や差し替えが多い番組での確認用です。

  • Settings / About

    設定に加え、リポジトリ・ライセンス・Discord・支援案内をまとめた画面があります。

Use cases

主な用途・利用例

  • マルチカメラの番組やイベント配信で、進行ディレクターと vMix オペレーターの連携を補助する
  • esports などシーン切替が多い番組で、繰り返し操作やショートカット整理の負荷を下げる
  • 社内・学校などで繰り返し使うフォーマット配信に、テンプレート化しやすい運用を載せる
  • Blank 入力や List の準備を、本番前のセットアップ時間にまとめて片付ける
