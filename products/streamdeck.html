Elgato Stream Deck plugins

8 plugins

配信機材を、キーひとつで。

vMix、ATEM、OBS、Roland、KAIROS、HyperDeckをStream Deckから直接操作するプラグインです。機材ごとに別のアプリを開かず、手元のキーとダイヤルに操作を集めます。

プラグイン一覧 GitHubで見る
  • Stream Deck 6.4以降
  • Windows / macOS
  • MIT / Apache-2.0
  • 篝火#16 採用

dev.mikanseilaboratory.vmix

Why

スイッチャーの画面を、もう見失わない。

Stream Deckはキーの画像を差し替えられるため、入力名やTallyをそのまま表示できます。プラグインは機材のAPIから状態を取り、押す前と押した後で表示を変えます。

状態を反映する

ATEMのProgram / Previewは、プラグイン内の状態ではなく実機のバス状態でキーの色を変えます。

複数台をまとめる

vMix、OBS、ATEMは名前付きで複数台を登録できます。予備系やサブ配信の操作も同じプロファイルに載せられます。

切断しても戻る

接続が切れたときはバックオフしながら再接続します。現場でWi-FiやLANが瞬断しても、手動で入れ直す必要を減らします。

ダイヤルにも対応

Stream Deck + のダイヤルを使うアクションを用意しています。回転と押し込みに別の操作を割り当てられます。

Plugins

8つのプラグイン

いずれもGitHub Releasesから.streamDeckPluginをダウンロードし、ダブルクリックでインストールできます。

vMix

streamdeck-studiocoast-vmix

v0.2.1

複数台のvMixを名前付きで登録し、InputとMixの一覧を実機から取得してキーに割り当てます。vMixのTCP API（Web Controller、既定ポート8099）を使います。

  • vMix（TCP API有効） / Stream Deck 6.4以降
  • Windows 10以降 / macOS 10.15以降
  • MIT License または Apache-2.0
ダウンロード ソース

ATEM

streamdeck-bmd-atem

v0.4.0

Cut、Auto、Program、Preview、Cut to Black、Fade to Black、AUX、DSK、Media Playerをキーに割り当てます。Program / Previewキーは実機のバス状態に合わせて色が変わります。

  • 複数台のスイッチャーとグループに対応
  • 切断時は1秒→2秒→4秒…（上限30秒）で再接続
  • Apache-2.0

Roland V-160HD

streamdeck-roland-v160hd

v0.1.0

Install

インストールは3ステップ

  1. 01

    ダウンロード

    各プラグインのReleasesから.streamDeckPluginを取得します。

  2. 02

    ダブルクリック

    Stream Deckソフトウェアの確認ダイアログでインストールします。アクション一覧にプラグイン名が表示されます。

  3. 03

    接続先を設定

    キーにアクションを置き、Property Inspectorで接続先と入力名を選びます。vMixはTCP APIを有効にしてください。

vMixの場合: Settings → Web Controller でTCP APIを有効にします。既定の127.0.0.1:8099は最初から登録されています。別PCのvMixはIPアドレスで追加してください。

FAQ

よくある質問

各社の公式製品ですか？

いいえ。vMix、ATEM、Roland、Panasonic KAIROS、HyperDeck向けのプラグインは非公式です。各社のサポート対象外となる場合があります。

複数台の機材を1つのプロファイルから操作できますか？

vMix、OBS、ATEMのプラグインは名前付きのインスタンスを複数登録できます。ATEMはグループを作り、1つのキーから複数台へ同時に送ることもできます。

接続できないときはどこを見ればいいですか？

vMixはTCP APIが有効になっているか（Settings → Web Controller、ポート8099）を確認してください。プラグイン側のログはWindowsなら %APPDATA%\Elgato\StreamDeck\logs、macOSなら ~/Library/Logs/ElgatoStreamDeck に出力されます。

ライセンスは何ですか？

vMix、OBS、ATEM、Roland、KAIROS、HyperDeckのプラグインはMITまたはApache-2.0です。Advanced HTTP ClientはリポジトリのLICENSEを確認してください。

不具合はどこに報告すればいいですか？

該当リポジトリのIssueへ、Stream Deckの機種、OS、プラグインのバージョン、接続先の機材と設定を添えて報告してください。
