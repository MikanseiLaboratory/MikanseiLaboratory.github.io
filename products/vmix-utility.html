vmix-utility

vmix-utilityは、vMixの接続管理、Shortcut URLの生成、Blank入力の一括作成、InputとListの確認をまとめたデスクトップアプリです。本番前の準備と、別PCからの操作にかかる時間を短くします。

Features

主な機能

接続先を登録し、必要な画面を切り替えて使います。vMix本体のHTTP / TCP APIを使います。

Connections

vMixホストを追加・管理します。複数台の切り替えや、予備系の確認に使います。

Shortcut Generator

Shortcut FunctionのURLを組み立てます。StreamDeckやブラウザからvMixを操作するときに使います。

Blank Generator

Blank / Colours入力を一括生成します。合成用のシーンを大量に作るときの作業を減らします。

Input Manager

Inputを一覧・管理します。名前の変更や状態の確認を、vMix本体とは別のPCから行えます。

List Manager

Input Listを確認・管理します。素材の差し替えが多い番組での確認用です。

Settings / About

設定、リポジトリ、ライセンス、Discord、支援の案内をまとめています。

Field

篝火#16での運用

2026年11月に開催された「篝火#16」で、vmix-utilityを採用いただきました。配信現場でのvMixの準備と、オペレーターの操作に使われています。

シーン数が多くスイッチングが多い番組では、Shortcutの整理とInput名の確認に時間がかかります。vmix-utilityは、その確認作業を本番前と本番中に分けて行えるようにします。

篝火#16での試験運用の記録（note）

  • シーン切替の多い番組

    Shortcutを整理します。StreamDeckやブラウザからの操作を組み立てやすくします。

  • 定型フォーマットの配信

    Blank入力をまとめて作ります。毎回のセットアップにかかる時間を短くします。

  • 別PCからの確認

    InputとListの状態を、vMix本体とは別のマシンから確認できます。

FAQ

よくある質問

対応OSは？

Windows（.msi）、macOS（.dmg、Intel / Apple Silicon）、Linux（.AppImage）向けにビルドした成果物を配布しています。

vMixのどのバージョンでも使えますか？

vMixのHTTP / TCP APIを使います。APIが有効なvMixであれば利用できますが、バージョンによって一部のShortcutや項目が異なる場合があります。

複数台のvMixを管理できますか？

はい。接続先を複数登録し、本番系と予備系を切り替えて使えます。
