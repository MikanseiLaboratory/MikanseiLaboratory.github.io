Iryx

vMixの操作を、手のひらに。

Iryxは、vMixのトランジションとリプレイに特化したハードウェアコントロールパネルです。画面のボタンをマウスで追う代わりに、物理キーとTバーで操作します。vMixのTCP APIに直接つなぎ、キーのLEDに現在の状態を返します。

導入・評価の相談 マニュアル
  • 2026年内 販売予定
  • LAN / USB-C
  • vMix 29以降
  • ATEMモード（SW-01）

What it is

スイッチャーの操作を、
画面から切り離す。

ライブ中のオペレーターは、確認する画面が多く、マウスのポインタを探す時間が思った以上にあります。Iryxは、よく使う操作を物理キーに固定し、視線を画面に残したまま操作できるようにします。

Transition

Cut、Auto、Tバー、Stinger、Overlay。vMixのトランジションをキーとフェーダーに割り当てます。

Replay

RP-00はリプレイ専用。Angleの切り替え、Channel選択、ジョグとTバーで再生位置を操作します。

Tally

vMixから受け取った状態をLEDに反映します。ProgramとPreviewの取り違えを減らします。

Direct API

キーボードエミュレーションではなく、vMixのTCP APIを直接叩きます。vMix側の設定に依存しません。

Models

用途で選べる3モデル

いずれもUSB-C給電で、有線LAN搭載モデルとUSB専用モデルがあります。ATEMモードは有線LAN搭載モデルのみです。

Iryxのモデル比較
モデル 用途 接続 主な操作
Transition Control TC-00 vMixのトランジション制御 LAN / USB Cut、Auto、Tバー、Stinger、Overlay、Mix選択
Transition Control SW-01 vMix / ATEMのトランジション制御 LAN / USB（ATEMはLANのみ） TC-00の操作に加え、ATEMモードでCut / Auto / Preview
Replay RP-00 vMixのリプレイ操作 LAN / USB Angle切り替え、Channel選択、ジョグ、Tバー

USB接続

USB CDC-NCMのイーサネットアダプターとして認識され、本機に172.31.x.1が割り当てられます。ドライバのインストールは不要です。

LAN接続

有線LAN搭載モデルは、DHCPでも固定IPでも運用できます。DHCPがない環境では約30秒後に192.168.1.100/24へフォールバックします。

FAQ

よくある質問

Iryxはいつ購入できますか？

2026年内の販売を予定しています。販売時期、価格、販売方法が確定したら、ニュースとXでお知らせします。

評価機を借りることはできますか？

評価機は開発者と合意した企業・個人に限定して頒布しています。現場での評価を希望する場合は、メールで用途と環境をお知らせください。

ATEMは操作できますか？

SW-01はATEMモードを備えており、UDP 9910経由でCut、Auto、Previewを操作できます。ATEMモードは有線LAN搭載モデルでのみ利用できます。

対応しているvMixのバージョンは？

vMix 29以降に対応しています。v28以前では、Stinger 5〜8、OverlayInput 5〜8、Mixの選択の一部が動作しない場合があります。

転売や譲渡はできますか？

できません。Iryxは評価用の試作機を含め、転売・譲渡を禁止しています。

保証はありますか？

開発中の試作機のため、市販品と同等の保護機能を備えていない場合があります。通常の製品保証はありません。
