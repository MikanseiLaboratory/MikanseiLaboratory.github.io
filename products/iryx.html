Iryx

vMixの操作を、手のひらに。

Iryxは、RP2040をベースにしたvMix専用のIPコントロールパネルです。MIDIやOSCではなく、vMixのTCP APIを直接叩きます。ShortcutやActivatorsの設定、ドライバのインストールなしで、USBケーブルを挿してから5〜10秒でボタンが反応します。

Background

現場ごとの設定から、解放する。

vMixはShortcutとActivatorsを設定すれば、MIDIコントローラーでもStreamDeckでも自由に操作できます。その自由度は強力ですが、現場ごとにボタンを作り直す必要があり、vMixへの理解も求められます。

Iryxは自由度をあえて捨て、ボタンの機能を固定しました。GPIOの押下を検知してTCP APIのFUNCTIONを直接呼ぶため、プリセットの読み込みも、ボタンへのショートカット割り当ても不要です。

設定なしで動く

vMixのIPと、Custom1〜4の割り当てを決めるだけ。ShortcutやActivatorsの作成は不要です。

右手に集約する

左手のStreamDeckでPreviewを選び、右手のIryxでCut、Fade、Stingerを実行する構成を想定しています。

押し心地を優先

KailhのCHERRY MX互換ホットスワップソケットを採用。軸を自分で選べます。初期出荷は赤軸です。

引き継げる操作

ボタン配置と機能が固定されるため、講習と本番で同じ操作感になります。後任への引き継ぎも短くなります。

How it works

物理キーから、vMixへ直結する。

間にMIDIやOSCの変換を挟まず、MCUからvMixのTCP APIを直接呼びます。

Direct TCP API

MIDI / OSCを介さず、vMixのTCP APIへ直接接続します。ボタンごとの機能をファームウェアで固定しています。

USB CDC-NCM

USB接続時はCDC-NCMのネットワークアダプターとして認識され、本機に172.31.x.1が割り当てられます。

LAN（W5500）

有線LAN搭載モデルはWiznet W5500でネットワークに接続します。DHCPでも固定IPでも運用できます。

Hot-swap

キースイッチはCHERRY MX互換のホットスワップ。付属の赤軸から、好みの軸へ交換できます。

Prototype

TC-00は、5台だけ配った評価機。

2026年5月、知人のvMixオペレーターにTC-00を5台配りました。筐体は未着手で、基板にスペーサーで足を付けた状態です。本番利用は推奨せず、フィードバックを集めるための頒布でした。

本体価格は無料で、希望額の寄付という形にしました。基板データの一部も提供したため、3Dプリンターがあれば筐体を自作できます。

TC-00のボタン構成

  • Custom1〜4（Stinger1〜4、Transition1〜4、Overlay1〜4などを割り当て）
  • Cut / Auto（AutoはFade以外にも変更可能）
  • Shift（同時押しで別の機能）
  • Menu / Back

評価で出た声

  • 押し心地が良い。赤軸とKailh Box Switch V2 Whiteの2種類を試した。
  • 設定なしで即運用できた。USB接続から5〜10秒で反応する。
  • Hold（長押し）モードが欲しい → 正式版で実装予定。
  • 内蔵ストレージにvMixのプリセットや確認用データを入れてほしい。
  • 左手用モデル、Hall Effect版が欲しい → 検討中。

Production

TC-01とSW-01は筐体・化粧箱付きで、USB-Cのロックコネクタに変更します。SW-01はStreamDeckモジュールを内蔵し、PCにはStreamDeckとIryxの2台として認識されます。頒布はBOOTHを予定しています。

Technology

RP2040の上に、現場の操作を積む。

ファームウェアはRust（Embassy）、ハードウェアはmizuyoukanが担当しています。

Rust + Embassy

RP2040向けのファームウェアはRustで開発しています。TC-00のコードは約10,000行で、大半はディスプレイ描画とUIです。

vmix-rs

vMixへの接続と制御には自作のRustライブラリvmix-rsを使っています。デスクトップのvmix-utilityとも資産を共有しています。

ST7789

本体の小型ディスプレイに接続状態、vMixのバージョン、PVW/PGMを表示します。

USB / LAN

USB CDC-NCMとDHCPサーバー、W5500によるTCP通信を実装しています。接続方法は筐体のモデルで選べます。

ハードウェア設計

回路設計・基板制作はmizuyoukanが担当。部品選定と仕様策定はFlowingが行っています。

RP2354Bを検討

RP-00はTバー、ジョグ、多数のボタンでRP2040のGPIOをすべて使い切ります。次の版ではRP2354Bへの移行も検討しています。

FAQ

よくある質問

Iryxはいつ購入できますか？

2026年内の販売を目指しています。TC-01とSW-01はBOOTHでの頒布を予定しています。販売時期と価格が確定したら、ニュースとXでお知らせします。

TC-00とTC-01/SW-01の違いは？

TC-00は9ボタンの試作・評価機です。TC-01はTC-00のフィードバックを反映した筐体付きの正式モデルで、USB-Cロックコネクタを採用します。SW-01はTC-01にStreamDeckモジュールを搭載し、vMixとATEMの両方を操作できます。

設定は必要ですか？

vMixのIPアドレスとCustom1〜4の割り当て程度です。ShortcutやActivatorsの作成、ドライバのインストールは不要です。USBで接続してから5〜10秒程度でボタンが反応します。

StreamDeckは必要ですか？

SW-01はStreamDeckモジュールを内蔵しています。TC-01とRP-00は、左手のStreamDeckでPreviewを選び、右手のIryxでトランジションやリプレイを操作する運用を想定しています。

ATEMは操作できますか？

SW-01はATEMモードを備えており、UDP 9910経由でCut、Auto、Previewを操作できます。ATEMモードは有線LAN搭載モデルでのみ利用できます。

対応しているvMixのバージョンは？

vMix 29以降に対応しています。v28以前では、Stinger 5〜8、OverlayInput 5〜8、Mixの選択の一部が動作しない場合があります。

価格はいくらですか？

正式版の価格は未定です。TC-00は2026年4月時点で9,980円前後を予定していましたが、正式モデルの価格は確定していません。

転売や譲渡はできますか？

できません。Iryxは評価用の試作機を含め、転売・譲渡を禁止しています。
